Star Runway — Orbital Flight: a 3D space flight game. Launch the StarRunner from Aurora Station, thread three glowing rings in orbit above a planet, and land back on the deck. Built with Three.js (vendored); the ship, station, planet, sun and moon are all procedural — no model files, no network needed.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
